# Habit Tracker 📋✨

A single-file habit tracker web app — track daily habits with categories, streaks, time ranges, and Chart.js analytics.

## Features
- ✅ Monthly check-off grid with per-habit categories
- ⏰ Start → end time ranges for each habit
- 🔥 Current & best streak tracking
- 📊 Charts: daily completion, category donut, weekly trend
- 🏆 Ranked summary table
- 💾 Data saved in browser localStorage
- 🎨 Hand-drawn floating doodles background

## Usage
Just open `index.html` in a browser — no build step or server required.
